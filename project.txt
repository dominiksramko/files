I'm creating an app called simply "files".

Features:
- user:folder association where the user can work with the files. the folder will be considered a root folder with all the paths inside queried will be relative to that. that means the app can be used by several people and each user has only one root folder.
- authentication is simply username:password
- those root folder will be mounted using docker (once in production)
- the ability to preview archives (even password protected ones) to see what files are inside
- ability to extract the archives (it will auto-detect if the archive has a single folder, if it does, extract to current folder, otherwise create a folder with the name same as the archive and extract the contents inside)
- ability to display images, videos, office suite files (word, excel, powerpoint), music
- ability to have admins that can create/modify users, default user is admin:admin
- ability to change own password

Stack:
Docker
Vue3 (TypeScript, Router, Pinia, Linter, Prettier)
Tailwind
Go (Gin)
SQLite (for storing users)
